7개 Template(화면 배치)마다 연결된 기능 수와 관련 기능을 공식 문서에서 확인한 서비스 수를 집계합니다. 서비스 수는 그 Template 전체 구현 확인이 아니며, 한 서비스는 여러 묶음에 중복될 수 있습니다.

12개 Organism(기능 영역)마다 연결된 기능과 공식 문서 확인 서비스를 집계합니다. P09와 P19는 두 기능 영역에 함께 연결되어 Organism의 기능 연결 합계는 34건이며, 서로 다른 기능은 32개입니다.

기능 32개를 Template(화면 배치)과 Organism(기능 영역)까지만 분해했습니다. 공식 문서 근거는 서비스의 실제 UI 전체를 시험했다는 뜻이 아닙니다.

셀의 확인 표시는 공식 문서에서 해당 동작을 직접 확인했다는 뜻입니다. 셀을 누르면 확인한 기능, 구현 차이, 사용자 역할과 근거 문서를 볼 수 있습니다.
